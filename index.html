leaves a print.

Discord bakes a permanent fingerprint into every user ID — the exact moment it was created, encoded right into the number. Enter one below and pull the public record behind it.

Any 15–22 digit snowflake. In Discord: enable Developer Mode, then right-click a user → Copy User ID.
Runs each ID one at a time. Bad or invalid lines are skipped and flagged in the results.
* Pulled from your own Cloudflare Worker, using Discord's official API — only what Discord already exposes for that ID. No login, no private data, and no way to go the other direction from a username. History is stored only in your own browser.

Anatomy of an ID

A snowflake is one number wearing five disguises — each ring below is a slice of it.

Outer ring — ms since Jan 1, 2015 (42 bits)
Ring 2 — internal worker ID (5 bits)
Ring 3 — internal process ID (5 bits)
Ring 4 — counter for same-ms IDs (12 bits)
  • IDs never change. Names and handles can, the number behind them can't.
  • The clock can't be faked. Creation date is baked into the ID itself.
  • Works on more than users — servers, messages, and roles use the same format.

Not provided
