Anatomy of an ID

A Discord ID is a "snowflake" — one number that quietly encodes when the account was made.

80351110224678912
First 42 bits — ms since Jan 1, 2015
Next 5 bits — internal worker ID
Next 5 bits — internal process ID
Last 12 bits — counter for same-ms IDs

Good to know

  • IDs never change. Names and handles can, the number behind them can't.
  • The clock can't be faked. The creation date is baked into the ID itself.
  • Works on more than users — servers, messages, and roles use the same format.
  • Nothing here needs a login. It's all already public.
