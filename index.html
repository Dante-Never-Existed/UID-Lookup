What's inside an ID

A snowflake is one number doing five jobs at once.

42 bitsTimestamp, in milliseconds since Jan 1, 2015
5 bitsWhich internal machine generated it
5 bitsWhich process on that machine
12 bitsA counter, in case two IDs land in the same millisecond

Worth knowing

 

Usernames and display names can be changed whenever someone likes, but the ID underneath stays fixed for the life of the account — which is what makes the timestamp trustworthy: it's arithmetic on the number itself, not something Discord reports separately and could get out of sync. The same format shows up on servers, messages, and roles too, so this trick isn't limited to user accounts.
